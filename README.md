# 🛒 BlinkIT Grocery Sales Dashboard (Excel)

An interactive Microsoft Excel dashboard built to analyze BlinkIT grocery sales using Pivot Tables, Pivot Charts, KPIs, Slicers, and Excel Dashboard techniques.

---

## 📊 Project Overview

This dashboard provides business insights into BlinkIT grocery sales performance.

It helps analyze:

- Total Sales
- Average Sales
- Number of Items Sold
- Average Rating
- Outlet Performance
- Item Categories
- Fat Content Analysis
- Outlet Size
- Outlet Location
- Sales Trends

---

## 🚀 Dashboard Features

- Interactive Slicers
- Dynamic Pivot Charts
- KPI Cards
- Outlet Analysis
- Product Category Analysis
- Sales by Location
- Fat Content Analysis
- Outlet Type Comparison

## 📈 Key Insights

- Tier-wise outlet performance varies significantly.
- Product categories show different demand patterns.
- Dashboard allows interactive filtering using slicers.
